# 업무자료 수집기 — Windows 배포

Windows 11 Intel/AMD 64비트(x64)용 설치파일과 사용자 안내를 제공합니다. 소스는 별도 비공개 저장소에서 관리하며, 회사 목록·설정·수집 자료·로그인 정보는 배포물에 포함하지 않습니다.

[최신 버전과 다운로드](https://github.com/Dubbi96/WehagoCollector-Releases/releases/latest)

0.3.8은 **전체 수집의 개별 오류를 기록하고 다음 회사를 처리합니다.** 조회 완료와 회사·계정·기간을 확인한 0건은 자료 없음입니다. 다운로드 요청 전의 행·메뉴 열기만 제한적으로 재확인하며, 요청 뒤 응답을 확인하지 못하면 자동 반복하지 않습니다. 로그인·계정·사무소·저장소·공통 화면 문제는 미완료를 보존하고 멈춥니다.

**4번 결과 폴더 → 수집기록**에서 회사별 CSV와 지원 JSON을 확인합니다. CSV에는 회사·방·상태·오류·다음 행동을 담고, 지원 JSON에서는 회사명·인증정보·원시 오류·조회 자료 값을 제외합니다. 기록 작성 버전·시각과 원래 실행을 구분합니다. **3번 최근 결과**에서 같은 실행의 미완료를 이어가거나, 종료된 실패·확인 필요만 새 실행에서 재수집합니다. 기존 파일과 원래 이력은 유지합니다.

[0.3.8 변경과 검증 범위](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.8)를 확인하세요. 합성 혼합 수집 회귀와 Windows 설치·0.3.7→0.3.8 자동 업데이트·합성 자료 보존 검증을 실제 고객 회사의 전체 다운로드와 구분합니다. 첨부 로그에는 보고된 1,677건 실패 실행이 없어 해당 회사의 실제 원인은 확정하지 않았습니다. 자료 복원·불러오기·재생성·원격 기수 변경은 이번 검수에서 실행하지 않았습니다.

이전 0.3.7은 **조건 확인과 안내 화면도 방향키로 바로 이동합니다.** 회사 선택·조건 요약·연도 제외 회사·고용 현황 최종 확인에서 ↑·↓는 한 줄(회사 선택에서는 한 회사), ←·→ 또는 PageUp·PageDown은 한 화면, Home·End는 처음·끝입니다. 홈·최근 결과·로그인 설정과 작은 창 안내는 방향키로 페이지를 넘깁니다. 입력 중인 숫자·문자는 유지하고, 메뉴 실행·조건 저장은 Enter로 제출합니다. 화면 이동이 수집·삭제·재생성 승인을 대신하지 않습니다.

[0.3.7 변경과 검증 범위](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.7)를 확인하세요. Mac 합성 터미널 화면과 Windows 실제 격리 콘솔 키 입력, 설치·0.3.6→0.3.7 자동 업데이트·합성 사용자 자료 보존을 검증했습니다. 이번 검수에서는 실제 WEHAGO 자료를 조회·복원·재생성하지 않았습니다. 고객 PC의 실제 키보드·IME·업무 수집은 별도 확인 대상입니다.

이전 0.3.6은 **근로자 고용 현황의 표 전환과 기존 자료 조회 검증을 보완합니다.** 정규직 29세·34세의 선택 연령·기간과 표시 표를 확인하고, 월별 인원·연도는 조회 응답과 대조합니다. 합계·금액은 위하고 화면이 재계산한 결과를 기준으로 비교합니다. 기수가 다르면 자동 변경하지 않고 중단합니다. Mac 실계정의 기존 2025~2026년 자료로 표 전환 6회, 표 3종·반복 다운로드 4회, Excel 196개 셀의 화면 일치를 확인했습니다. 자료 복원·불러오기·재생성·기수 변경은 실행하지 않았습니다.

[0.3.6 변경과 검증 범위](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.6)를 확인하세요. Windows 설치·0.3.5→0.3.6 자동 업데이트·합성 자료 9파일 보존 검증과 고객 Windows PC의 실제 WEHAGO 수집은 구분합니다.

이전 0.3.5부터 **설치·업데이트 시 제품 바로가기의 아이콘을 갱신합니다.** 현재 설치 EXE를 가리키고 추가 실행 인수가 없는 기본 바탕화면 바로가기를 갱신하며, 다른 대상·사용자 지정 인수의 바탕화면 링크는 보존합니다. 시작 메뉴·바탕화면·앱 제거 목록에는 버전별 앱 아이콘 파일을 직접 지정합니다. 시스템 아이콘 캐시 삭제나 Explorer 재시작은 수행하지 않습니다. Windows 자동시험에서 실제 바로가기 속성과 합성 사용자 자료 9개 파일의 전후 해시를 확인했으며, 고객 PC의 화면 표시는 별도 확인 대상입니다.

0.3.4부터 **메인 메뉴 번호를 화면 순서에 맞춥니다.** 왼쪽 수집·결과는 1~4번, 오른쪽 관리는 5~9번이며 종료 0번은 아래에 따로 표시합니다. 다음 행동·오류 안내와 실제 실행 기능도 같은 번호를 사용합니다.

- 1 고용 현황 / 2 분개장 / 3 최근 결과 / 4 결과 폴더
- 5 전체 회사 목록 / 6 프로그램 업데이트 / 7 로그인 설정 / 8 설치 확인 / 9 오류 기록

[0.3.5 변경과 검증 범위](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.5)를 확인하세요. 회사 목록·설정·수집 자료의 저장 위치와 형식은 유지합니다.

이전 0.3.3은 **2026년 분개장 수집과 대량 준비 오류**를 개선합니다. 준비 단계에서는 검증된 회계기간을 재사용하고 추가 정보만 조회 API로 확인합니다. 준비 건수·대상·경과·중단 코드를 보여 주며, 미확인 회사는 자료 없음과 구분하고 사용자가 제외에 동의해야 진행합니다. 엑셀 메뉴가 나타나지 않으면 다운로드 전에 메뉴 열기만 한 번 다시 시도합니다. 복원·재생성·삭제를 이번 검수에 사용하지 않았고, 복원 상태를 자동으로 해결하려고 원천 자료를 변경하지 않습니다.

[0.3.3 변경과 검증 범위](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.3)를 확인하세요. 실제 Mac 계정의 전체 준비와 단일 회사 다운로드, Windows 자동 설치·업데이트 및 합성 자료 보존을 각각 구분해 기록했습니다. 원래 실패한 고객 회사와 고객 PC의 실제 조작은 별도 확인 대상입니다.

기존 **회사 목록 방향키 이동**도 유지합니다. ↑·↓는 한 항목, ←·→ 또는 PageUp·PageDown은 한 화면, Home·End는 처음·끝으로 이동합니다. 화면 끝에서는 목록이 한 줄씩 따라 움직이며 Enter로 강조된 회사를 선택합니다. `/`로 검색, `m`으로 여러 회사·전체 입력, `?`로 도움말을 엽니다. 이동·검색·취소는 저장 목록을 사용합니다. 마우스 휠은 기존 콘솔 동작을 사용합니다. 방향키를 지원하지 않는 터미널은 화면에 표시된 n/p 또는 ]/[와 Enter를 사용합니다.

0.3.1의 **로그인 시 Chrome 최소화**와 EXE·설치파일에 포함된 **문서 수집 아이콘**은 유지합니다. 기본 제품 바로가기는 0.3.5 설치 시 갱신합니다. 이름을 바꾸거나 다른 실행 대상을 지정한 링크는 별도 확인 대상입니다. 아이디·비밀번호는 CMD 안내에 따라 입력하고, 추가 인증이 필요할 때 안내 후 수집용 창을 표시합니다.

같은 프로그램에서 **1번 근로자 고용 현황**과 **2번 분개장**을 선택합니다. 고용 현황의 정규직 청년 만 29세 이하·만 34세 이하 기준과 비정규직 상단 통계표를 하나 이상 선택하거나 모두 내려받습니다. 회사 검색·목록 재사용·200개 단위 조회, 현재 단계·진행·결과·다음 행동 표시를 제공합니다.

## 기존 설치판 업데이트

수집이 끝난 뒤 **현재 0.2.3~0.3.3은 8번, 0.3.4 이상은 6번 프로그램 업데이트 → 0.3.8 확인 → y**를 선택합니다. 다운로드·검증·프로그램 종료·자동 설치·재시작을 진행하며, 같은 버전이면 다시 설치하지 않습니다. GitHub 로그인이나 별도 운영 서버는 필요하지 않습니다.

회사 목록·설정·인증 캐시·이력·수집 자료는 같은 자료 폴더에 유지합니다. 기본 위치는 `%LOCALAPPDATA%\WehagoCollector`입니다. WEHAGO 세션이 만료되면 다시 로그인해야 합니다.

## 처음 설치하거나 0.2.1·0.2.2에서 전환

최신 Release의 설치 EXE를 실행합니다. Python·라이브러리·수집용 Chromium이 포함되어 Git·Python·개발 도구를 따로 설치하지 않습니다. 설치 이후에는 프로그램의 업데이트 메뉴를 사용합니다.

0.3.8 Guides ZIP을 압축 해제하고 `시작하기.html`, `메뉴-테스트-가이드.html`, `전체수집-업데이트-안내.md`, `검증결과.md`를 확인하세요. 이번 안내는 MD·HTML 5개이며 새 PDF·화면 캡처를 포함하지 않습니다. 이전 준비·수집 오류 보충 PDF와 화면 9장은 [0.3.3 Release](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.3), 전체 수집 절차 PDF 46쪽·캡처 122장은 [0.3.0 Release](https://github.com/Dubbi96/WehagoCollector-Releases/releases/tag/v0.3.0)에 보존합니다. 이전 화면을 새 버전의 재시험으로 표시하지 않습니다.

## 사용·검수 시 확인

- 고용 현황의 기존 작성 조회는 작성 자료의 저장·재생성을 차단합니다. 목록 갱신 후에도 기수가 다르면 담당자가 실제 회사 화면의 기수를 확인해야 하며, 프로그램은 자동 변경하지 않습니다. 새 불러오기는 같은 기간의 원격 작성 자료 전체를 재생성하므로 영향 확인 후 `재생성` 입력이 필요합니다. 선택한 통계표는 다운로드 범위입니다.
- 합성 로그인 창 시험·자동 설치/업데이트 검사와 고객 PC의 실제 조작을 구분합니다. 상세 증거와 미시험 범위는 릴리스 기록과 동봉 검증 결과를 참고하세요.
- 설치파일은 전자서명 전 검증판입니다. 회사 보안 정책에 따라 확인 창이나 실행 차단이 발생할 수 있습니다.

## 배포 파일 확인

Release의 파일 목록과 `SHA256SUMS.txt`를 확인할 수 있습니다. 프로그램은 GitHub가 제공하는 설치파일 크기와 SHA-256을 대조한 뒤 설치합니다. 설치가 시작된 뒤 실패했다면 같은 정식 설치파일로 복구 설치한 후 버전을 확인해주세요.
