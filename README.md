# 업무자료 수집기 — Windows 배포

Windows 11 Intel/AMD 64비트(x64)용 설치파일과 사용자 안내를 제공합니다. 소스는 별도 비공개 저장소에서 관리하며, 회사 목록·설정·수집 자료·로그인 정보는 배포물에 포함하지 않습니다.

[최신 버전과 다운로드](https://github.com/Dubbi96/WehagoCollector-Releases/releases/latest)

0.3.0에서는 **1번 근로자 고용 현황**과 **2번 분개장**을 같은 프로그램에서 선택합니다. 고용 현황의 정규직 청년 만 29세 이하 기준·만 34세 이하 기준·비정규직 상단 통계표를 하나 이상 선택하거나 모두 내려받습니다. CMD 화면에는 전체 처리 건수·진행률, 현재 회사·단계, 결과와 다음 행동을 표시합니다. 회사 검색·목록 재사용·200개 단위 조회와 기존 자료 위치를 유지합니다.

## 기존 설치판 업데이트

0.2.3 이상 설치판에서는 수집이 끝난 뒤 **8. 프로그램 업데이트 → 새 버전 확인 → y**를 선택합니다. 다운로드·검증·프로그램 종료·자동 설치·재시작을 진행하며, 같은 버전이면 다시 설치하지 않습니다. GitHub 로그인이나 별도 운영 서버는 필요하지 않습니다.

회사 목록·설정·인증 캐시·이력·수집 자료는 유지하고 같은 자료 폴더로 다시 실행합니다. 기본 위치는 `%LOCALAPPDATA%\WehagoCollector`입니다. WEHAGO 세션이 만료되면 다시 로그인해야 합니다.

## 처음 설치하거나 0.2.1·0.2.2에서 전환

최신 Release의 설치 EXE와 Guides ZIP을 내려받습니다. ZIP을 폴더 구조 그대로 압축 해제하고 `시작하기.html` 또는 PDF를 읽어주세요. 설치파일을 한 번 실행하면 이후에는 프로그램에서 업데이트할 수 있습니다. Git·Python·개발 도구는 별도로 설치하지 않습니다.

안내 ZIP에는 **46쪽 전체 검수 PDF, 순서도·체크리스트, 화면 기록 HTML과 PNG 122장**이 있습니다. 119장은 실제 프로그램의 합성 Mac PTY 화면이며, 3장은 민감정보를 가린 실제 WEHAGO 화면입니다. Windows PC의 실제 화면 캡처와 구분해 표시했습니다. 화면 기록을 보려면 동봉된 이미지 폴더도 함께 압축 해제해야 합니다.

## 사용·검수 시 확인

- 고용 현황의 기존 작성 조회는 원격 저장을 차단합니다. 새 불러오기는 같은 기간의 원격 작성 자료 전체를 재생성하므로 영향 확인 후 `재생성` 입력이 필요합니다. 선택한 통계표는 다운로드 범위입니다.
- Mac 실제 계정의 목록·분개장·허용 회사의 고용 상단 3표를 확인했습니다. Windows 자동 설치·업데이트 검사와 고객 PC의 실제 조작은 구분합니다. 상세 증거와 미시험 범위는 릴리스 기록 및 동봉 검증 결과를 참고하세요.
- 설치파일은 전자서명 전 검증판입니다. 회사 보안 정책에 따라 확인 창이나 실행 차단이 발생할 수 있습니다.

## 배포 파일 확인

Release의 파일 목록과 `SHA256SUMS.txt`를 확인할 수 있습니다. 프로그램은 GitHub가 제공하는 설치파일 크기와 SHA-256을 대조한 뒤 설치합니다. 파일 해시는 제작자 전자서명을 대신하지 않습니다. 설치가 시작된 뒤 실패했다면 같은 정식 설치파일로 복구 설치한 후 버전을 확인해주세요.
