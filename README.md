# 위하고 분개장 수집기 — Windows 배포

Windows 11 Intel/AMD 64비트(x64)용 설치파일과 사용자 안내를 제공하는 저장소입니다.
제품 소스는 별도의 비공개 저장소에서 관리합니다. 고객의 회사 목록·설정·수집 자료·로그인 정보는 배포물에 포함하지 않습니다.

[최신 버전과 다운로드](https://github.com/Dubbi96/WehagoCollector-Releases/releases/latest)

## 처음 설치하거나 0.2.1·0.2.2에서 전환할 때

최신 Release의 설치 EXE와 전체 가이드 PDF를 내려받아 주세요. HTML 안내를 보려면 작은 안내 ZIP을 압축 해제한 뒤 `시작하기.html`을 읽어주세요.
설치파일을 한 번 실행한 뒤 바로가기로 프로그램을 엽니다. Git·Python을 따로 설치할 필요가 없습니다.
`메뉴-테스트-가이드.html`에 메뉴별 순서도·예상 결과·확인란이 있습니다.

## 다음 버전으로 업데이트할 때

0.2.3 이상 설치판에서는 수집이 끝난 뒤 **8. 프로그램 업데이트**를 선택합니다.
새 정식 버전이 있으면 동의 후 다운로드·검증·프로그램 종료·자동 설치·재시작을 진행합니다.
같은 버전이면 다시 설치하지 않습니다. GitHub 로그인이나 별도 운영 서버는 필요하지 않습니다.

프로그램 파일과 사용자 자료는 별도 위치에 있습니다. 업데이트는 기존 회사 목록·설정·수집 자료를 보존하고 같은 데이터 폴더로 다시 실행합니다.
기본 자료 위치는 `%LOCALAPPDATA%\WehagoCollector`입니다. 로그인 세션의 유효기간은 서비스 정책에 따라 달라집니다.

이 제품은 전자서명 전 검증판입니다. 회사 PC 보안 정책에 따라 실행 확인이나 차단이 발생할 수 있습니다.
실제 로그인·분개장 다운로드는 사용 권한과 대상 환경에서 별도로 확인해야 합니다.

## 배포 파일 확인

Release의 파일 목록과 SHA256SUMS.txt를 확인할 수 있습니다. 프로그램은 GitHub가 제공하는 설치파일 크기와 SHA-256을 대조한 뒤 설치합니다.
파일 해시는 제작자 전자서명을 대신하지 않습니다. 설치가 시작된 뒤 실패했다면 같은 정식 설치파일로 복구 설치한 후 버전을 확인해주세요.

이 저장소에는 인증정보나 고객 자료를 올리지 마세요.
